THE LIMIT, stated. Jira's request to create an issue has no 'only if there is none like it' condition. Two runs
at the same moment, each with its own preview, could both create the subtask. Each run counts the subtasks with
this title after it writes, and ends with 'MORE THAN ONE' and exit code 2 if there are two. That case is in the
tests (test_the_same_subtask_created_by_someone_at_the_last_moment_is_reported), and cannot be staged from the
command line. A person would notice it by that message, or by two subtasks with one title under the story.
