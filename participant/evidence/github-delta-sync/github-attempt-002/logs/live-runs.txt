Three real runs. github-delta-sync, attempt github-attempt-002

Run by the participant in their own terminal, against GitHub, with a fine-grained token limited to one private
sandbox repository: Issues read-only, Pull requests read-only, Metadata read-only. The repository holds two
made-up issues and one made-up pull request. Between run 1 and run 2 the participant added one comment to
issue 1 by hand and left issue 2 alone.

The output went to scratch folders outside the repository, shown here as SCRATCH and SCRATCH-FULL. The lines
below are what the sync printed, copied by the assistant from the saved output, with the repository's owner and
id replaced by [owner] and [repository id]. Nothing else was changed. The token was never shown to the assistant.

Before run 1 the same command was run once in a terminal where the token had not been exported. The sync
stopped before contacting GitHub, with "the environment variable GITHUB_TOKEN is not set", and wrote nothing.
