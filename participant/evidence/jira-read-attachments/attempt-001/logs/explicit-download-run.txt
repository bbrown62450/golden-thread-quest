------------------------------------------------------------------------------
The limits this tool applies before it saves an attachment.

SIZE: at most 5.0 MB, by what Jira states and again by counting the bytes as they arrive.

TYPE: only these. The last extension of the name, the type Jira states, and how the file's own bytes begin must all agree.
  .csv   Jira may state text/csv or text/plain;      the bytes must be text: readable as UTF-8, no zero byte, not beginning as another kind of file
  .jpeg  Jira may state image/jpeg;                  the bytes must begin as that kind of file begins
  .jpg   Jira may state image/jpeg;                  the bytes must begin as that kind of file begins
  .json  Jira may state application/json;            the bytes must be JSON, readable as UTF-8 text
  .log   Jira may state text/plain;                  the bytes must be text: readable as UTF-8, no zero byte, not beginning as another kind of file
  .md    Jira may state text/plain or text/markdown; the bytes must be text: readable as UTF-8, no zero byte, not beginning as another kind of file
  .pdf   Jira may state application/pdf;             the bytes must begin as that kind of file begins
  .png   Jira may state image/png;                   the bytes must begin as that kind of file begins
  .txt   Jira may state text/plain;                  the bytes must be text: readable as UTF-8, no zero byte, not beginning as another kind of file
  Anything else is refused: archives, programs, scripts, office documents, web pages, SVG pictures, and a name with no extension.

NAME: refused if it has a slash, a `..`, a character that cannot be seen, or a space or dot at its end. It is never used as a path.

THE SCAN, a short list of patterns and NOT antivirus: the published antivirus test string; a program or archive inside the file; in a PDF, a script
or something set to run; in text, a private key, a script's first line or a script tag; in a CSV, a cell a spreadsheet would run as a formula.
