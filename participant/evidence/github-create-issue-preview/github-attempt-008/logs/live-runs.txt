The real runs. github-create-issue-preview, attempt github-attempt-008

The participant ran these in their own terminal, against their private sandbox repository on GitHub, which holds
only made-up issues. The assistant sent no request to GitHub and never saw the token. The token was a fine-grained
one, limited to that repository, with Issues and Contents set to read-only. It could not write. The output was
saved to scratch files outside this repository. This is a masked copy: the owner's login is shown as [owner] and
the repository's id as [repository id]. Nothing else was changed.

Before the runs the participant added an issue template to the sandbox by hand: the file
.github/ISSUE_TEMPLATE/bug_report.md, with the same four sections as the made-up one.

The draft, its source notes, the local index and the allowlist were written by the assistant in a scratch folder
outside this repository, shown here as SCRATCH. The draft is a made-up bug. The index holds the one sandbox issue
saved in the github-read-issue quest. The allowlist names one repository, the sandbox.
