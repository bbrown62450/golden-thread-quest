The real runs. github-create-issue, attempt github-attempt-009

The participant ran these in their own terminal, against their private sandbox repository on GitHub, which holds
only made-up issues. The assistant sent no request to GitHub and never saw the token. The token was a fine-grained
one, limited to that repository, with Issues set to read and write and Contents to read-only. The output was
saved to scratch files outside this repository. This is a masked copy: the owner's login is shown as [owner], the
issue's node ID as [node id], the repository's id as [repository id], and the name the participant typed with
--confirmed-by as "the participant". Nothing else was changed. The draft, the saved preview, the local link and
the result record of these runs stay outside the repository.

Every command had these arguments, with SCRATCH for the scratch folder:

    --source live --draft SCRATCH/draft.md --allowlist SCRATCH/allowlist.json --link SCRATCH/linked.md

The draft is a made-up bug, the one previewed on the sandbox in the last quest. The allowlist named one repository.
