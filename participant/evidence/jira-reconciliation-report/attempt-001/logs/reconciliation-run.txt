1. THE STATES, as the tool states them
$ python3 skills/jira-reconciliation-report/reconcile.py states
------------------------------------------------------------------------------
The states, in the order they are tried. An item is given the first that fits, and no other.

  1. failed to fetch        Jira could not be asked about it, or did not answer with an item. Nothing else can be said about it.
  2. missing from Jira      Jira answered that it is not there.
  3. conflicted             Jira has changed it since it was copied, and the copy was changed locally.
  4. changed locally only   The copy was changed locally. Jira has not changed.
  5. stale                  Jira has changed it since it was copied. The copy has not been changed locally.
  6. not yet copied         Jira lists it. The local copy does not hold it.
  7. synchronized           None of the above: Jira has what the copy has.  (not an exception)

A stale item gives its age, which is how long the copy has been behind Jira, and the limit, which is 24 hours.
A failed item gives one of these classes, and nothing Jira said: forbidden (403); network error; rate limited (429); server error (5xx); timed out; unexpected status; unreadable answer.
